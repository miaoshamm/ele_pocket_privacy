Privacy Policy for ElePocket

Last updated: 2026-11-18

ElePocket (the "Extension") is a browser extension that lets users drag web images and files to auto-sync to user-configured WebDAV cloud storage.

Data We Process

  • Authentication information: WebDAV server address, username, password or token, saved locally in browser storage. This is required to connect to your WebDAV server.
  • Website content: Images and files you explicitly drag into the extension. The extension only reads these resources upon your manual drag or right-click action.

What We DO NOT collect

We do NOT collect browsing history, IP address, health, financial, personal identity, chat messages or user activity tracking data.

Where your data goes

All WebDAV credentials and upload task records are stored locally inside your browser. Dragged files and images are transmitted directly to the WebDAV server that you configure. No user data is sent to the developer’s server.

Data Sharing

We do not sell, rent or share your data with any third parties. Data is only sent to your own WebDAV endpoint for upload.

Permissions explanation

  • activeTab: Temporarily access the current tab only when you drag or right-click resources.
  • storage / unlimitedStorage: Save WebDAV settings and upload task records locally.
  • offscreen: Run background WebDAV upload logic without blocking web pages.
  • alarms: Schedule retry for failed upload tasks.
  • contextMenus: Add right-click menu to send images/files to ElePocket.
  • Host permission: Communicate with your custom WebDAV server.

Remote Code

This extension does not load or execute any remote JavaScript code. All code is bundled within the extension package.

Your control

You may clear stored WebDAV credentials in extension settings, or uninstall the extension to erase all local saved data.
